# 产业链深度拆解

## 方法论基础

| 模块 | 来源 | 解决的问题 |
|------|------|-----------|
| **WBS** (Work Breakdown Structure) | 军工/航天 | 怎么拆？拆到什么程度？怎么保证不漏？ |
| **BOM 用量** | 制造业/成本核算 | 每台终端产品用多少个？为什么是这个数量？ |
| **FBS** (Function-Behavior-Structure) | 工程设计学 | 这个组件为什么存在？怎么实现的？技术路线差异的根源在哪？ |
| **子组件技术方案** | 供应链工程 | 这个组件的每个零件，目前有哪些技术方案可选？ |
| **TRL** (Technology Readiness Level) | NASA | 这项技术多成熟？离量产还有多远？ |
| **市场数据** | 行业研究 | 这个产品/组件全球出多少货？市场多大？增速多少？ |

## 第一部分：WBS 分解 + BOM 用量

### WBS 分解规则

**100%规则**：每个父节点的所有子节点加起来，必须恰好等于父节点的全部。不能多，不能少。如果拆出来说"GPU子系统包含：GPU芯片、显存、供电……和其他"，那"其他"是什么？要么写出来，要么没拆完。

**互斥规则**：同一父节点下的子节点不能有重叠。如果"散热"和"液冷系统"同时出现在第一层，说明散热包含液冷，层次错了。

**可交付规则**：每个节点必须是一个可识别的、物理或功能上可验证的东西。"平台层"不是可交付的。"GPU核心芯片GH100"是可交付的。

### 层级定义

| 层级 | 命名 | 定义 | 示例 |
|------|------|------|------|
| Level 0 | 终产品 | 被拆解的完整产品 | 800G OSFP DR8光模块 |
| Level 1 | 子系统 | 可独立测试的物理/功能单元 | 光发射子系统(TOSA) |
| Level 2 | 组件 | 子系统内的功能模块 | 激光器芯片 |
| Level 3 | 子组件 | 组件内的可替换单元 | 有源层(MQW) |
| Level 4 | 零件/材料 | 不可再分的制造单元 | InP衬底 |
| Level 5 | 基础材料 | 原材料/基础化学品 | 高纯铟、高纯磷 |

### 终止条件

满足以下**任一**条件即停止：

| 条件 | 示例 |
|------|------|
| 到达基础原材料（从矿石/化工原料加工而来） | 高纯硅、InP晶圆、铜箔、光刻胶 |
| 到达标准工业元器件（有统一规格书，多家可产） | 0402贴片电阻、M3螺丝、标准光纤连接器 |
| 到达基础物理/化学原理（不可更改的自然规律） | 半导体能带理论、热力学第二定律、麦克斯韦方程 |
| 到达标准工艺步骤（行业通用的制造步骤） | EUV曝光、ALD沉积、CMP平坦化 |

> 不满足以上任一条件 = 没拆完，继续拆。

### 拆解模板

```

├── S1: [名称] — [功能] — 用量: [X个/台]

│   │   │   └── ...
│   │   └── SC1.1.2: ...
│   ├── C1.2: ...

### BOM 用量

对WBS分解树的**每个非叶子节点**，标注用量。这是理解产业链的关键——有些组件虽然单价不高，但用量极大，整体市场规模惊人。

> BOM用量是后续市场分析的基石。**全球市场总需求 = 单台用量 × 全球出货量**。没有用量数据，市场分析就是空中楼阁。

#### 用量标注规则

| 规则 | 说明 |
|------|------|
| 以终端产品为基准 | 所有用量以"每台终端产品需要多少个/多少量"来计算 |
| 区分离散件和连续件 | 离散件（芯片、隔离器）用"个/台"；连续件（胶水、焊料、散热膏）用"g/台"或"mg/台" |
| 区分必选和可选 | 如果某个组件在某些配置中才有，标为"视配置，1-2个/台" |
| N+1冗余 | 如果系统有冗余设计（如N+1电源），标注为"3+1个/台"并说明冗余策略 |
| 不同规格的同一品类 | 如果同一种组件在系统中用量不同（如不同位置的导热垫厚度不同），汇总为"导热垫: Xg/台（含Y种规格）" |

#### 用量推演

用量不是拍脑袋的，必须从系统架构推演出来：

```
800G光模块的用量推演:
- 隔离器: 1个/TOSA, 1个TOSA/光模块 = 1个/光模块
  但如果用EML方案可以不用外置隔离器 → 0个
- 透镜: 激光器准直×1 + 光纤聚焦×1 + 隔离器两端各×1 = 4个/光模块
  (如果有MUX还需要额外透镜)
- 金丝键合: 连接激光器驱动到激光器, 约3-5根/通道 × 8通道 = 24-40根/光模块
```

#### 用量汇总表模板

在整个WBS分解完成后，从叶子往根汇总：

```
| WBS路径 | 组件 | 单台用量 | 用量依据 |
|---------|------|---------|---------|
| 光模块→TOSA→隔离器 | 隔离器 | 1个 | 每TOSA标配1个(非EML方案) |
| 光模块→TOSA→透镜 | 透镜 | 4个 | 准直1+聚焦1+隔离器两端各1 |
| 光模块→DSP→ADC/DAC | ADC | 8个 | 8通道信号采集, 1个/通道 |
| 光模块→电气接口→金丝键合 | 金丝 | ~32根 | 4根/通道×8通道 |
| 光模块→封装→导热垫 | 导热垫 | 0.5g | DSP散热1片+激光器温控1片 |
```

## 第二部分：FBS 三层分析

对拆出来的**每一个组件**（WBS Level 2及以下），做FBS三层分析。

### 三层定义

| 层 | 问题 | 说明 |
|----|------|------|
| **Function（功能）** | 这个组件在系统中实现什么目的？输入什么？输出什么？ | 功能是"做什么"，不是"怎么做"。光模块的隔离器：功能是"阻止反射光返回激光器"，不是"用法拉第旋转效应" |
| **Behavior（行为）** | 通过什么物理/化学/数学原理实现这个功能？ | 行为是原理层。同一个功能可能有多种行为来实现。隔离器：磁光效应 vs 声光效应 vs 波导非互易性 |
| **Structure（结构）** | 用什么具体物理结构/材料/工艺来实现这个行为？ | 结构是物理层。磁光隔离器：YIG晶体 + 永磁体 + 偏振片 + 准直器 |

### FBS的价值

**Function不变，Behavior和Structure会变**——这就是"技术路线"的根源。

| 组件 | Function | Behavior（不同技术路线） | Structure（每条路线对应） |
|------|---------|----------------------|----------------------|
| 800G光调制器 | 把电信号调制到光上 | ① 电吸收调制(EAM) ② 马赫-曾德尔干涉(MZM) ③ 直调激光器(DML) ④ 薄膜铌酸锂(TFLN) | 每条B对应一组S |
| GPU显存 | 高速存取GPU计算数据 | ① HBM垂直堆叠 ② GDDR平面布线 | HBM3→硅中介层+TSV / GDDR7→PCB走线 |

### FBS分析模板

对每个组件，输出：

```
组件: [WBS路径, 如: 光模块→TOSA→激光器芯片]

Function:
  在系统中实现 [具体目的]。输入 [X]，输出 [Y]。

Behavior（可能有多个技术路线）:

  路线1: [名称]
    原理: [物理/化学/数学机制]
    关键材料/设备: [需要什么来实现]
    优势: [比起别的路线好在哪]
    劣势: [差在哪]
    成熟度(TRL): 见第四部分

  路线2: [名称]
    (同上结构)

  ... (所有已知路线)

Structure:
  路线1的具体物理实现: [结构描述]
  路线2的具体物理实现: [结构描述]
```

## 第三部分：子组件技术方案枚举

FBS分析到Structure层后，**Structure本身还可能由多个子零件组成**，每个子零件又有自己的技术方案。这部分就是把这些子零件的技术方案全部列出来。

### 为什么要做这一步

以光模块的隔离器为例：

- FBS Structure告诉你：隔离器 = 磁光晶体 + 偏振片 + 永磁体 + 准直器
- 但你还需要知道：**偏振片本身有几种做法？准直器有几种做法？**

如果不拆到这一层，你就不知道"偏振片"这个看似简单的零件，其实有薄膜型、线栅型、双折射晶体型三条技术路线，各自有不同的工艺难度和供应商格局。

### 枚举方法

对每个组件，先列出它的**子零件清单**（从WBS拆解中得到），然后对每个子零件，列出当前产业使用的**所有技术方案**。

```
组件: 隔离器

子零件清单:
├── 磁光晶体 (1个/隔离器)
├── 偏振片 (2个/隔离器, 输入侧+输出侧)
├── 永磁体 (1个/隔离器)
└── 准直器 (2个/隔离器, 输入端+输出端)

各子零件的技术方案:

磁光晶体:
  方案1: YIG (钇铁石榴石) — 主流, 隔离度>35dB, 需外加永磁体
  方案2: Ce:YIG (掺铈YIG) — 法拉第旋转系数更大, 可缩小晶体尺寸
  方案3: Bi:YIG (掺铋YIG) — 可单片集成到硅光平台, TRL 4-5

偏振片:
  方案1: 金属线栅偏振片 — 铝线阵列, 高消光比, 耐高温, 主流
  方案2: 介质薄膜偏振片 — SiO2/TiO2多层膜, 低损耗, 波长敏感
  方案3: 双折射晶体偏振片(Glan-Taylor) — 最高消光比, 体积大/贵
  方案4: 聚合物薄膜偏振片(PVA掺杂碘) — 最便宜, 耐温差(<80°C)

永磁体:
  方案1: SmCo (钐钴) — 高温稳定, 价格适中, 主流
  方案2: NdFeB (钕铁硼) — 磁力更强但温度漂移大, 需补偿
  方案3: 电磁体 — 可调磁场, 功耗大体积大, 仅实验室用

准直器:
  方案1: GRIN透镜 (梯度折射率) — 小体积, 易对准, 主流
  方案2: 非球面透镜 — 更高耦合效率, 体积大/对准难
  方案3: 球透镜 — 最便宜, 耦合效率最低, 短距低速
```

### 枚举要求

- **每个子零件至少列出2种技术方案**（只有1种 → commodity，不需要深研）
- **标注主流方案**（当前产业用得最多的那个）
- **标注各方案优劣势**（一句话）
- **关联上层FBS**：子零件的技术方案选择，直接影响上层组件走哪条Behavior路线

## 第四部分：TRL 成熟度评估

对每项技术的**每条技术路线**打分。

> TRL只做**评分 + 判断依据**。技术路线的动态追踪（时间线、卡点、量产预测）在第五部分单独处理。

### TRL 量表

| 级别 | 名称 | 判断标准 |
|------|------|---------|
| TRL 1 | 基础原理 | 论文发表了，物理上可行 |
| TRL 2 | 技术概念 | 有应用设想，算过可行性 |
| TRL 3 | 概念验证 | 实验室里跑通了，关键参数达标 |
| TRL 4 | 实验室验证 | 在模拟环境下完整跑通 |
| TRL 5 | 原型验证 | 在接近真实环境下验证 |
| TRL 6 | 工程样机 | 工程样机在真实环境演示 |
| TRL 7 | 小批量产 | 小批量试产，良率在爬坡 |
| TRL 8 | 量产验证 | 量产工艺定型，良率达标 |
| TRL 9 | 大规模商用 | 大规模出货，多家客户使用 |

### 评分要求

- 必须标注判断依据。不能拍脑袋。
- 如果是LLM知识库的信息，标注 `[知识库]`
- 如果查到了最新的技术新闻/论文，标注 `[来源: ...]`
- 如果不确定当前TRL，标注 `[估计, 需验证]`

## 第五部分：最新技术方案与落地追踪

这是对TRL的动态补充。TRL告诉你"现在在哪"，这部分告诉你**"正在往哪走，谁走得更快"**。

> 与第四部分的边界：第四部分只做评分+依据；本部分做**时间线 + 产业化卡点 + 关键突破事件 + 预计量产时间**。

### 追踪维度

对每项技术路线，追踪以下信息：

| 追踪维度 | 说明 |
|---------|------|
| **当前主流方案** | 产业大规模采用的是哪条路线？TRL 8-9的那条 |
| **下一代方案** | 目前处于TRL 4-7的路线中，哪条最可能成为下一代主流？ |
| **前沿探索** | TRL 1-3的路线中，哪些在学术/工业实验室里取得了关键突破？ |
| **关键突破时间线** | 过去12个月内的重大节点（首次演示/样机发布/小批量产/客户送样/良率突破） |
| **产业化卡点** | 这条路线卡在哪个具体问题上还没解决？（材料？工艺？设备？成本？良率？生态？） |
| **预计量产时间** | 业界公认的商用时间窗口 |

### 技术路线演进图模板

对关键组件，画一张时间轴：

```
组件: [WBS路径]

2024 ←────────────────────────────→ 2030

路线A (当前主流, TRL 9):
  ├── 2024Qx: [当前产能/良率/出货量]
  └── 未来: [路线A的下一代演进方向]

路线B (下一代, TRL 5-7):
  ├── 2024Qx: [关键突破事件]
  ├── 2025E: [预计里程碑]
  └── 2027E: [预计量产时间]

路线C (前沿, TRL 1-4):
  ├── 2024: [最新论文/实验室突破]
  └── 远期可能: [如果成功意味着什么]
```

### 落地情况判断标准

对每条技术路线，明确给出以下判断：

| 落地阶段 | 标志 | 你要问的问题 |
|---------|------|------------|
| 实验室 | 论文发表/实验室演示 | 关键参数能否达到实用要求？ |
| 工程样机 | 原型机/开发板/alpha样品 | 尺寸/功耗/可靠性距实用还有多远？ |
| 客户送样 | 送到客户手里测试 | 客户反馈如何？测试通过率？ |
| 小批量产 | 有产线，有订单 | 良率？产能规划？单位成本？ |
| 规模量产 | 大规模出货 | 市占率？客户数量？扩产计划？ |
| 主流商用 | 成为行业标准方案 | 还有替代威胁吗？ |

> 对每条技术路线，给出当前的落地阶段，以及到达下一阶段需要克服什么。

## 第六部分：市场数据

技术拆解让你知道"这个东西是什么"，市场数据让你知道"这个东西有多大"。

### 需要查询的数据维度

| 维度 | 查询内容 | 粒度 |
|------|---------|------|
| **终端产品出货量** | 全球年出货量、增速(CAGR)、按地区/速率/规格细分 | 按年/按季度 |
| **组件市场规模** | 每个关键组件的全球市场规模($)、出货量(个) | 组件级别 |
| **ASP变化趋势** | 平均售价走势、降价曲线 | 组件级别 |
| **产能数据** | 全球总产能、产能利用率、扩产计划 | 关键瓶颈组件 |
| **渗透率** | 新技术路线在总市场中的占比变化 | 技术路线级别 |

> 如果组件的市场数据是基于终端产品数据推算的（如隔离器出货量=光模块出货量×单台用量），必须在来源中标注推算逻辑。

### 交叉验证

同一个市场数据，至少从2个不同来源确认：
- 行业分析机构: LightCounting, Yole, Omdia, Counterpoint, IDC
- 学术/行业协会: IEEE, OFC, CIOE
- 公司财报/投资者演示（注: 这部分在Phase 2公司映射阶段再做）

如果两个来源的数据差异>20%，取两者的区间，标注"数据存疑"。

## 第七部分：分层输出——让非专业用户也能看懂

技术拆解的正确性和可读性必须兼得。底层用完整的 WBS/FBS/TRL 表格保证严谨，上层用**类比翻译**和**关键洞察卡片**让非技术用户秒懂。

### 四层输出结构

每一部分内容，同时输出四个层次：

```
Layer 1 (摘要层)          —— 一段大白话，任何人都能看懂
Layer 2 (类比结构图)       —— 用日常事物类比，画成树
Layer 3 (关键洞察卡片)     —— 6个问题，每个一句话回答
Layer 4 (完整技术表格)     —— WBS + FBS + TRL 全量表，给需要深挖的人
```

### Layer 1: 摘要层 — 大白话版

**规则**：每个子系统用一段话，按此模板写：

```
[S子系统名称] 是 [产品] 的 [日常类比（如：发货站/大脑/血管/空调）]，
负责 [一句话功能]。它里面最关键的是 [最重要的1-2个组件]，
因为 [一句话说明为什么关键——是性能瓶颈？成本大头？还是最容易坏？]。
目前这个子系统最难做的是 [最大的技术难点]，
业内正在往 [下一代方向] 演进。
```

**示例**：

```
TOSA（光发射子系统）是光模块的"发货站"，
负责把电信号变成光信号发出去。
它里面最关键的是激光器芯片和调制器——
激光器决定了信号能传多远，调制器决定了信号能传多快。
目前最难做的是把激光器和调制器在硅光芯片上集成到一起（硅光集成），
因为硅本身不发光，需要在硅上"嫁接"InP材料，工艺极难。
业内正在从分立InP方案往硅光集成方案演进，预计2027年前后规模商用。
```

### Layer 2: 类比结构图

**规则**：用日常生活的东西来类比每个子系统，画成一棵可读的树。每个节点要有：技术名 → 类比名（一句话功能）。

```
800G光模块 = 一个微型快递处理中心

├── TOSA = 发货窗口
│   ├── 激光器 = 打印机（把空白纸变成有字的纸 = 产生光）
│   ├── 调制器 = 写快递单的（把地址写到包裹上 = 把电信号刻到光上）
│   ├── MUX复用器 = 多车道合并成一条高速
│   ├── 透镜 = 传送带（把光送进光纤）
│   ├── 隔离器 = 单向旋转门（只出不进，防止退货）
│   └── TEC温控 = 空调（让激光器温度恒定，否则会"中暑"）
│
├── ROSA = 收货窗口
│   ├── 光电探测器 = 扫码枪（把光信号变回电信号）
│   ├── TIA跨阻放大器 = 放大镜（把微弱信号放大到能用）
│   └── DEMUX解复用器 = 一条高速分出多车道
│
├── DSP芯片 = 翻译+质检中心
│   ├── ADC = 笔迹识别（把模拟信号变成数字信号）
│   ├── 数字信号处理 = 翻译官（把乱码修好/还原）
│   └── DAC = 打字机（把数字信号变回模拟信号）
│
├── 电气接口 = 快递站的大门（连接交换机）
│
└── 封装/散热 = 快递站的外墙+空调系统
```

> **类比原则**：
> - 不要用另一个专业术语来类比，用日常生活的东西
> - 类比不需要精确，但需要帮助理解**这个东西在整个系统里的角色**
> - 每个类比后面跟一句括号说明，解释这个类比对应什么技术动作

### Layer 3: 关键洞察卡片

**规则**：对每个关键组件，输出一张"洞察卡片"，回答非专业用户真正关心的6个问题。每个问题用一句话回答，不超过30字。

> 以下为**示例输出格式**，实际使用时按此模板填写：

```
┌─────────────────────────────────────────┐
│  组件: 隔离器 (光模块→TOSA→隔离器)         │
├─────────────────────────────────────────┤
│  干嘛的？  像单向旋转门，光只能出不能进       │
│  为什么重要？ 没它激光器会坏，信号会乱        │
│  难在哪？   需要在米粒大的晶体上精确控制磁场   │
│  谁控制？   日本供应商主导，工艺经验壁垒深     │
│  用量多大？ 每个光模块1个，全球一年1.2亿个    │
│  会变吗？   硅光集成方案可能把它集成到芯片里   │
└─────────────────────────────────────────┘
```

**6个标准问题**（普适，不限于某个产业）：

| 问题 | 用这个句式回答 |
|------|-------------|
| 干嘛的？ | 像 [日常类比]，负责 [核心功能] |
| 为什么重要？ | 没它的话 [后果]；它决定了 [性能指标] |
| 难在哪？ | [材料/工艺/设计] 层面需要 [具体难点] |
| 谁控制？ | [国家/地区] 供应商主导，因为 [原因]。**只写区域/国家，不写具体公司名** |
| 用量多大？ | 每个 [终端] 用 [X] 个，全球一年 [Y] 的量级 |
| 会变吗？ | 下一代可能 [演进方向]，[预计时间] |

> **Phase 1 公司名铁律**："谁控制"只能用区域/国家来回答（如"日本供应商主导"、"台湾代工厂垄断"），**严禁出现任何具体公司名称**。具体公司留到 Phase 2 映射阶段再补。

### Layer 4: 完整技术表格

这就是前六部分产出的 WBS + FBS + TRL 全量表。**Layer 4的存在是为了让Layer 1-3经得起推敲**。如果有人质疑Layer 3的任何一个结论，可以翻到Layer 4看完整的技术依据。

### 分层输出示例：整份报告的顶层结构

```

> **铁律**：不管你拆得有多深、多对，如果Layer 1-3不能让一个不懂技术的人看懂——你的输出就是不合格的。

## 执行纪律

1. **100%规则不可侵犯**。如果拆出来后有几项不知道是什么，说明你没拆完。
2. **FBS从Function开始，不是从Structure开始**。先问"它做什么"，再问"怎么做的"。很多分析失败是因为跳过了Function，直接进入了Structure。
3. **一条技术路线 = 一个 (Behavior + Structure) 对**。如果两条路线的Behavior相同、只有Structure不同（比如同样的磁光原理，不同厂家的YIG晶体配方），它们是同一个路线的不同实现，不是两条路线。
4. **TRL不能被"感觉"赋值**。每个TRL值必须有判断依据。标注来源。
5. **落地追踪要有时间线**。不能只说"在研发中"——什么时候开始研发的？关键节点在什么时候？预计什么时候量产？
6. **Phase 1 不写公司名**。FBS分析对象是技术，不是公司。公司是下一阶段的事。"谁控制"只能用区域/国家回答（如"日本供应商主导"），严禁出现具体公司名称。
7. **对每条技术路线一视同仁**。不要因为路线1是主流就只详细分析路线1。路线2和3虽然还没量产，但它们是理解产业方向的关键。
